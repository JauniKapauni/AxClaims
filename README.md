# AxClaims
> Minecraft plugin that allows players to claim regions of a world
---
## Requirements
- Minecraft Paper 26.1.2 Server
---
## Features
- Player can create region
- Player can remove region
- Player can use menu command
- Player will see particle visualization
- Player will get actionbar message on entering/leaving
- Flags
  - BlockBreak
  - BlockPlace
  - PVP
---
## Installation
1. Download the latest release
2. Put the `.jar` into the `/plugins` folder
3. Start the server
