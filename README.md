# AxClaims
Minecraft plugin that allows players to claim regions of a world

---
## Commands & Permissions
- `/buyclaimblocks` - `axclaims.buyclaimblocks`
- `/claim` - `axclaims.claim`
- `/menu` - `axclaims.menu`
- `/recenter` - `axclaims.recenter`
- `/trust` - `axclaims.trust`
- `/trustlist` - `axclaims.trustlist`
- `/untrust` - `axclaims.untrust`
